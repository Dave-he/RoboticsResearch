## 6. 关键不确定性与风险

- **数据瓶颈**:高质量真实操控数据稀缺(sim2real gap)
- **可靠性**:长尾场景下的故障率未达工业可用
- **能源密度**:电池技术限制工作时间(典型 2-4 小时)
- **安全认证**:家庭场景下的 ISO/UL 标准尚未成熟
- **价格 vs 价值**:工业场景 ROI 仍未跑通(除特定重复任务)

## 9. 2026-09-29 增量观察(FULL-TEXT 修订版)

> 本节基于当日 4 篇论文的 **PDF 全文**,替换 2026-09-29 上午基于摘要的初版判断。

### 9.1 强信号:力感知 VLA,两条路线均有硬数据

| | **Opt2VLA** (2609.23968) | **VisForce** (2609.25785) |
|---|---|---|
| 机构 | **Georgia Tech IRIM** | 未标注 |
| 路线 | **接口层**(力作为 VLA 显式输出) | **表示层**(力渲染进图像) |
| 底座 | **GR00T N1** | **π0.5** |
| 载体 | **Agility Digit** 人形(48 kg, 30 DoF / 20 驱动) | UR10 + **Inspire RH56F1** + 2× RealSense D405 |
| 数据 | **TO 合成 + 控制器 rollout** | **手部演示,每任务仅 25–30 次** |
| 关键结果 | C0 40.0% → C7 **82.2%** joint SR | π0.5 20% → VisForce **70%**(T2) |
| 项目页 | **opt2vla.github.io**(承诺发布力感知数据集) | 无 |

**⭐ 对行业最可操作的一条结论**:

> **力的「表征方式」比「有没有力」重要一个数量级。**

- Opt2VLA:力矩 **原生状态拼接 27.8% → 专用编码器 74.4%** → 加辅助未来力矩损失 **82.2%**
- VisForce:同样力接地图,**token 拼接 10/5/15% → cross-attention 70/55/40%**

**对厂商的直接影响**:

| 厂商 | 影响 |
|---|---|
| **NVIDIA(GR00T)** | 力接口范式可被 GR00T 直接产品化(本文底座即 GR00T N1) |
| **Physical Intelligence** | 同理(VisForce 底座即 π0.5)。**两家头部 VLA 已被独立验证** |
| **Inspire Robots** | RH56F1(6-DoF 低价手)+ VisForce ≈ **低成本力控平台**,算法增值层 |
| **Agility Robotics** | Digit 的差异化能力候选 |
| **物流/分拣集成商** | **变重量抓取**是真实痛点(视觉无法区分同外观不同重量的箱子,只有力能) |
| **力传感器厂商** | ⚠️ **中性,非利好** —— 两篇都**没省掉力传感器**,只换了编码方式。但可降规格(5 个粗量程驱动力) |

**另一条对 VLA 训练有价值的发现**:Opt2VLA 的 C8(全量微调 VLM)overall 75.6% < C7(冻结 VLM 骨干)82.2% —— **冻结骨干 + 只训 connector/action model 反而更好**。

### 9.2 最重要事件:7-DoF 全线性手做到 $500(冲击 §1.3)

**The Cartesian Hand(2609.25696)** · **Duke University** · **DARPA FoundSci + TIAMAT + ARO + ARL 资助**

**实测规格(全文,非推断)**:

| 指标 | 数值 | 对比参考 |
|---|---|---|
| **整机成本** | **~$500**(含七舵机) | Shadow Hand ~$100k;Allegro ~$20k+ |
| **3D 打印件** | PLA $30 / SLS Nylon 12 $50 | 仅占整机 **6–10%** |
| 质量 | **850 g** | ≈ Allegro 量级 |
| 自由度 | **7,全部线性** | Shadow 24 / Allegro 16(多旋转) |
| 峰值推力 | 170 N(理论) | 持续握持 **2 kg** |
| 关节速度 | ~60 mm/s | 偏慢,快速节拍可能不足 |
| 能力覆盖 | 35 物体 / 7 类机构化操作 | 实验室 + 制造 + 家居 |
| 开源 | 承诺 software + hardware,**未放出** | 需持续跟踪 |

**降本杠杆点(推断,基于 BOM 结构)**:打印件仅占 6–10% → **舵机占 BOM 约 85%**。**舵机选型与国产替代是该路线的真正杠杆点**,建议单独跟踪。

**对 §1.3 现有格局的判断**:

| 现有玩家 | 变化 |
|---|---|
| Shadow / Allegro / LEAP(高 DoF + 腱绳) | **性价比叙事被削弱** —— $500 做到 7 类机构化操作 |
| **平行夹爪**(Robotiq / DH-Robotics) | **最直接受益者**:加 $500 模块化扩展件即得"抓后可动"。这是**产品升级路径,不是竞品对抗** |
| **Inspire(RH56 系列)** | 同价位带另一条路线(该手走渲染力 + π0.5) |
| 实验室自动化(专用单工位设备) | **一只可换工具的手替代多个夹具** |
| 人形厂商(Figure / Tesla / 1X / Unitree) | 视觉与力控管线依赖多关节手标定,中期不构成替代,长期是成本压力 |

**DARPA 四个项目同时资助是强产业信号** —— 强于任何论文本身。

**最大风险**:**耐久数据完全缺失**(数千次循环磨损 / 舵机寿命 / 打印件疲劳),且无成功率统计。$500 是实验室价,**不是量产价**。

### 9.3 越界入册:野外空中操控(分量低于评分)

**Aerial Manipulation(2609.30521)** · **Penn State 航空航天系** · **IROS 2026 MoMA.v5 workshop,5 页**

全文核实后的实际情况:

- 任务:空中插销入孔(**20 mm 杆 → 50 mm 孔,离地 130 cm**)
- 策略:条件 Diffusion Policy,**80 次室内 UMI 手持演示**,**零样本**迁移到未见户外草地
- 状态估计:**FAST-LIO2**,无外部动捕
- 控制:全身 MPC,状态 $[p,v,\eta,\omega,q\in\mathbb{R}^4]$,输入 $[f,\tau,q_{ref}]$
- **样本量:室内 5 次 + 室外 3 次,共 8 次,全部成功**
- 结果:Norm. EE Error 室内 0.102 / 室外 0.104;Max Base Tilt 3.32° / 1.84°

**行业判断**:3/3 成功在 95% 置信下真实成功率下界仅约 **44%** —— 这**没有证明系统可靠**。该子方向瓶颈不在控制算法,而在**整机可靠性、失效安全、监管许可**。真实高空作业中**人工 + 安全绳至今优于任何无人系统**。

**协议处理**:§1 明确将无人机列为暂不纳入范围(单独建库),本篇标 `scope_note`,**不进入核心跟踪线**。

### 9.4 读 workshop 论文的默认折扣(新增方法论)

Aerial Manipulation 暴露了本项目的一个读法问题:摘要只说 "demonstrate successful outdoor manipulation tasks",**全文核实后是 3 次试验**。

**本项目约定**:读 workshop / 会议短文(< 6 页)时,
- **"全部成功"必须追问试验次数 N**
- N < 20 时,结论一律标注"可行性证明"而非"可靠性证明"
- 本项目已把该约定记入协议执行经验
