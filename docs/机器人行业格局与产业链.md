## 6. 关键不确定性与风险

- **数据瓶颈**:高质量真实操控数据稀缺(sim2real gap)
- **可靠性**:长尾场景下的故障率未达工业可用
- **能源密度**:电池技术限制工作时间(典型 2-4 小时)
- **安全认证**:家庭场景下的 ISO/UL 标准尚未成熟
- **价格 vs 价值**:工业场景 ROI 仍未跑通(除特定重复任务)

### 9.1 强信号:力感知 VLA,两条路线均有硬数据

| | **Opt2VLA** (2609.23968) | **VisForce** (2609.25785) |
|---|---|---|
| 机构 | **Georgia Tech IRIM** | 未标注 |
| 路线 | **接口层**(力作为 VLA 显式输出) | **表示层**(力渲染进图像) |
| 底座 | **GR00T N1** | **π0.5** |
| 载体 | **Agility Digit** 人形(48 kg, 30 DoF / 20 驱动) | UR10 + **Inspire RH56F1** + 2× RealSense D405 |
| 数据 | **TO 合成 + 控制器 rollout** | **手部演示,每任务仅 25–30 次** |
| 关键结果 | C0 40.0% → C7 **82.2%** joint SR | π0.5 20% → VisForce **70%**(T2) |
| 项目页 | **opt2vla.github.io**(承诺发布力感知数据集) | 无 |

**⭐ 对行业最可操作的一条结论**:

> **力的「表征方式」比「有没有力」重要一个数量级。**

- Opt2VLA:力矩 **原生状态拼接 27.8% → 专用编码器 74.4%** → 加辅助未来力矩损失 **82.2%**
- VisForce:同样力接地图,**token 拼接 10/5/15% → cross-attention 70/55/40%**

**对厂商的直接影响**:

| 厂商 | 影响 |
|---|---|
| **NVIDIA(GR00T)** | 力接口范式可被 GR00T 直接产品化(本文底座即 GR00T N1) |
| **Physical Intelligence** | 同理(VisForce 底座即 π0.5)。**两家头部 VLA 已被独立验证** |
| **Inspire Robots** | RH56F1(6-DoF 低价手)+ VisForce ≈ **低成本力控平台**,算法增值层 |
| **Agility Robotics** | Digit 的差异化能力候选 |
| **物流/分拣集成商** | **变重量抓取**是真实痛点(视觉无法区分同外观不同重量的箱子,只有力能) |
| **力传感器厂商** | ⚠️ **中性,非利好** —— 两篇都**没省掉力传感器**,只换了编码方式。但可降规格(5 个粗量程驱动力) |

**另一条对 VLA 训练有价值的发现**:Opt2VLA 的 C8(全量微调 VLM)overall 75.6% < C7(冻结 VLM 骨干)82.2% —— **冻结骨干 + 只训 connector/action model 反而更好**。

### 9.2 最重要事件:7-DoF 全线性手做到 $500(冲击 §1.3)

**The Cartesian Hand(2609.25696)** · **Duke University** · **DARPA FoundSci + TIAMAT + ARO + ARL 资助**

**实测规格(全文,非推断)**:

| 指标 | 数值 | 对比参考 |
|---|---|---|
| **整机成本** | **~$500**(含七舵机) | Shadow Hand ~$100k;Allegro ~$20k+ |
| **3D 打印件** | PLA $30 / SLS Nylon 12 $50 | 仅占整机 **6–10%** |
| 质量 | **850 g** | ≈ Allegro 量级 |

| 峰值推力 | 170 N(理论) | 持续握持 **2 kg** |

**对 §1.3 现有格局的判断**:

| 现有玩家 | 变化 |
|---|---|
| Shadow / Allegro / LEAP(高 DoF + 腱绳) | **性价比叙事被削弱** —— $500 做到 7 类机构化操作 |
| **平行夹爪**(Robotiq / DH-Robotics) | **最直接受益者**:加 $500 模块化扩展件即得"抓后可动"。这是**产品升级路径,不是竞品对抗** |
| **Inspire(RH56 系列)** | 同价位带另一条路线(该手走渲染力 + π0.5) |

### 9.3 越界入册:野外空中操控(分量低于评分)

**Aerial Manipulation(2609.30521)** · **Penn State 航空航天系** · **IROS 2026 MoMA.v5 workshop,5 页**

全文核实后的实际情况:

- 任务:空中插销入孔(**20 mm 杆 → 50 mm 孔,离地 130 cm**)
- 策略:条件 Diffusion Policy,**80 次室内 UMI 手持演示**,**零样本**迁移到未见户外草地
- 状态估计:**FAST-LIO2**,无外部动捕
- 控制:全身 MPC,状态 $[p,v,\eta,\omega,q\in\mathbb{R}^4]$,输入 $[f,\tau,q_{ref}]$
- **样本量:室内 5 次 + 室外 3 次,共 8 次,全部成功**
- 结果:Norm. EE Error 室内 0.102 / 室外 0.104;Max Base Tilt 3.32° / 1.84°

**行业判断**:3/3 成功在 95% 置信下真实成功率下界仅约 **44%** —— 这**没有证明系统可靠**。该子方向瓶颈不在控制算法,而在**整机可靠性、失效安全、监管许可**。真实高空作业中**人工 + 安全绳至今优于任何无人系统**。

**协议处理**:§1 明确将无人机列为暂不纳入范围(单独建库),本篇标 `scope_note`,**不进入核心跟踪线**。

### 9.4 读 workshop 论文的默认折扣(新增方法论)

Aerial Manipulation 暴露了本项目的一个读法问题:摘要只说 "demonstrate successful outdoor manipulation tasks",**全文核实后是 3 次试验**。

- **"全部成功"必须追问试验次数 N**

- 本项目已把该约定记入协议执行经验

## 10. 2026-10-12 增量观察:成本结构正在被重估(三篇同期研读)

> 来源:[Dex-One2Many](reports/DexOne2Many_2610.12470_研读报告.md)(2610.12470)、
> [A Balanced Data Diet](reports/BalancedDataDiet_2610.12465_研读报告.md)(2610.12465)、
> [PhoneBot](reports/PhoneBot_2610.08737_研读报告.md)(2610.08737)

### 10.1 冲击 §1.1:开源双足人形的地板价被打到 $400 —— 但没有手

PhoneBot 把开源小型人形的入门价从 **$3,500**(HighTorque MiniPi)拉到 **约 $400**,且**感知套件反而最全**(手机相机 + IMU + 触摸屏 + 麦克风)。

**但必须同时记住三件事**:

| 事实 | 含义 |
|---|---|
| **无手臂** | 13 DoF 全部花在下肢(12)+ 躯干偏航(1)。**它是一台会走路的手机云台,不是能干活的人形** |
| **扭矩 1.4 N·m** | 舵机 DYNAMIXEL XL430-W250,2.0 rad/s 后力矩跌到 0.08 N·m。**成本优势完全是用扭矩换来的** |
| **同价位无工业能力** | 1.8 kg / 0.48 m / 平地-only / 无急停。**若目标是操控,$500–2,000 的桌面机械臂比它更有用且更便宜** |

> ⚠️ **本项目对该价格的读法**:"$400"是**教育与科研市场的真地板价**(此前 $3.5K),但**不是人形机器人的产业地板价**。**引用这个数字时必须同时说明它没有手。**

### 10.2 冲击 §3 成本结构:关节模组的成本底线被重新发现

PhoneBot 的 BOM 是本项目至今**唯一可核算到底**的:

```
13 × DYNAMIXEL XL430-W250 @ $23.90  =  $310.70   (占整机约 78%)
SBC + 结构件 + 电子件 + 电池(倒推)   ≈  $90
                                    ─────────
                                       约 $400
```

**这条算式揭示的成本结构事实**:在一台 13 DoF 的人形里,**关节占了 78%**。因此:

- **降价的第一杠杆永远是关节,不是结构件也不是算力**;
- ⚠️ **但 $23.90 的关节换来的是 1.4 N·m**。谐波减速器 + 无框电机方案单件 **$200–2,000 / 10–50 N·m**。**价格与扭矩是同一枚硬币的两面,不能只要便宜的**;
- **加手臂的算术**:13 舵机已占 78%,加 4–6 DoF 手臂 → 19–23 个舵机 → **即使沿用 $23.90 也要 $600–800,且 1.4 N·m 握力不足必须换舵机档位 → 成本优势被抹平**。⚠️ **这是 PhoneBot 路线的结构性天花板,不是工程排期问题。**

### 10.3 新增风险项:复用消费电子会引入新的锁定与安全债

| 新风险 | 证据 | 产业含义 |
|---|---|---|
| **GMS 锁定** | Honor 9 因无 Google 服务**直接无法使用 ARCore SLAM** | ⚠️ **「复用手机」的方案在部分品牌手机上功能降级**。评估此类平台时必须逐型号验证 |
| **低层环走 Wi-Fi** | 50 Hz(20 ms)+ UDP,**全文零延迟表征** | ⚠️ **控制稳定性依赖网络,这是与总线架构的根本差异**。家庭/儿童场景不可接受 |

### 10.4 反向信号:三篇共同削弱「真机数据工厂」叙事

本日三篇各自从不同角度削减数据/算力需求,但**共同指向同一结论 —— 瓶颈不在算法,在资产构造与真机保真度**:

### 10.5 意外收获:两样可以直接搬走的工程资产

本项目认为 PhoneBot 硬件新闻价值一般,但有两项**可复现性最高的技术细节值得单独归档**:

1. **矢状面镜像增强(sagittal mirroring)**:关节角对称误差 **0.254 → 0.003 rad**(约 85×),左右力矩不平衡 **0.205 → 0.034**。**可移植到任何双足/四足项目,零硬件依赖。**
2. **把消费级舵机的缺陷显式建模并在训练中随机化** —— 齿隙 **0.02–0.1 rad**(激活载荷 0.1 N·m)、摩擦 **0.069 N·m**、通电阻尼 **0.162 N·m·s/rad**、指令偏移 **±0.05 rad**、被动/主动刚度比 3.0。
   > 🔑 **这是全文最值得学的做法**:低成本硬件论文通常回避讲缺点,**PhoneBot 把齿隙、摩擦、力矩衰减全部量化并写进仿真**。⚠️ **注意 0.1 rad 齿隙在踝关节 ≈ ±5.7° 位置不确定性,直接对应跌倒风险** —— 这条应作为本项目评估任何低价关节模组时的必查项。

## 11. 2026-10-16 增量观察:三篇同日研读交叉印证的三条产业链变化

### 11.1 🔴 真机学习的数据门槛正在塌陷 —— 且塌陷路径不是「更强的遥操作」

本日两篇**互不相关的独立工作**给出了同向的硬数字:

| 来源 | 环节 | 传统做法 | 本日证据 | 量级差 |
|---|---|---|---|---|
| **HiFun**(HKUST+ETH) | 协调策略的初始数据 | **150–100 min/任务 人工臂手演示** | **13–34 min/任务 自动 DMP rollout**(成功率 100% / 100%,人工为 85% / 100%) | **约 1/4** |
| **ACCRUE**(NVIDIA) | 每阶段基座适配演示 | 每个新 SKU 一整套流程 | **仿真 1–50 条;真机 5–10 条**(SpaceMouse) | 量级下降 |
| **ACCRUE** | 新任务的后续 RL 交互 | 每任务从零重启,**全额支付** | **真机机器人时间节省 31.0–68.5%** | **1/3–2/3** |

🔑 **对产业链的直接含义**:

1. **「遥操作数据工厂」的成本模型需要修订。** 现行模型假设 *成本 ∝ 演示小时数*。HiFun 证明:**如果任务有可解析的运动学参考(一个位姿序列),演示量可以降到近乎为零**。**这不是「更便宜的遥操作」,而是「遥操作在很多工序上可以被自动生成替代」。**
2. **但必须同时记住 HiFun 保留的成本项**:运动学先验(**kinesthetic teaching < 5 min/任务**)+ 判别器数据(**4–13 min/任务**)+ 在环训练。**边际成本没有归零,只是从「小时级数据工程」转移到了「分钟级专家在场」。**
3. **受影响最大的产业环节**:机器人遥操作数据采集服务 / 数据工厂类创业公司。**若客户的工序具备可描述的几何结构,其护城河(采集规模)将被显著削弱。**

## 12. 2026-10-19 增量观察:三篇同日研读交叉印证的两条产业链变化

本日三篇(全部已取 arXiv PDF 全文)研读 **Spark-0**(触觉预训练)/ **FastVLA**(VLA 推理压缩)/ **LIN-SLAM**(神经隐式 SLAM 边缘部署),分属三个不相关子领域,却指向同一条主线。

### 12.1 🔴 「实时」正在从加分项变成准入门槛,而门槛是按**部署算力**而非方法新颖度划线的

**三篇的算力位置对照表**:

| 论文 | 关键算力事实 | 门槛性质 | 门槛有多硬 |
|---|---|---|---|
| **Spark-0** | **96 GPU × 400k 步**预训练(⚠️ GPU 型号论文未给),Fine-tune 另 80k 步 | **训练期算力** | 🔴 极高。本报告估算为数十万美元量级 ⚠️ 非论文给出。**这道门槛把绝大多数高校实验室与企业挡在外面** |
| **FastVLA** | **完全免训练**,**单张 RTX 4090** 完成全部实验(含真机) | **推理期算力** | 🟢 几乎为零。零训练成本 + 消费级显卡 |
| **LIN-SLAM** | **Jetson Orin NX**(边缘模组),GPU 均值 **82.4% / 86.9%**,peak 99%,每帧 84.875 / 88.401 ms vs 100 ms 周期 | **部署期算力** | 🔴 高。**余量仅约 15%** |

🔑 **对产业链的意义**:

1. **如果一个方法只在「算力充裕」的设定下成立,它对 2026 年的产业没有意义。** Spark-0 的 +19.27 点跨本体增益**必须先花 96 卡才拿得到**;LIN-SLAM 的第二贡献(C++/CUDA 优化)**只在边缘模组上才产生价值**,换工作站 GPU 这个贡献归零。
2. **三篇中唯一「零门槛」的是 FastVLA** —— 这直接决定它的采纳速度。⚠️ **本报告判断:2026 年具身智能论文的产业影响,可能与「复现门槛」的相关性高于与「指标提升」的相关性。**
3. 📌 **建议固化为本项目常设维度:每篇研读必须标出「训练算力 / 推理算力 / 部署算力」三栏**,因为这三栏决定了不同的读者能不能用。

### 12.2 ⚠️ 数据不是越多越好:Spark-0 给出了本项目迄今最硬的一次「域对齐度 > 数据量」证据

**Spark-0 Table 4 的这组数字值得单独归档**:

| 变体 | Ego Humanoid(跨本体、纯视觉部署) | 说明 |
|---|---|---|
| **Scratch**(不预训练) | **58.34%** | 基线 |
| **Visual PT**(用同一批 1,000 h 数据,但**丢弃触觉**) | **52.45%** | ⚠️ **掉了 5.89 点** |
| **100H**(保留 100 h 触觉) | 59.42% | 勉强超过 Scratch |
| **1000H**(保留 1,000 h 触觉) | **71.72%** | **+19.27 点(vs Visual PT)** |

🔑 **两个必须分开读的事实**:

1. 🔴 **视觉预训练让跨本体迁移变差了。** Scratch → Visual PT 掉 5.89 点。预训练里 **662 h 是 EgoDex 人类第一视角视频**(采样权重 0.39,是所有来源中最高的)。⚠️ **本报告推断:模型过拟合到人类视角的视觉域,因此损害跨本体迁移。论文只解释了触觉在 Sim 上收益小的原因,未直接解释这一下降。**
2. ✅ **触觉预训练在同一批 RGB 上加了 19.27 点。** 两个变体共享**完全相同的 RGB 数据**,唯一差异是丢弃/保留触觉 —— **这是本项目迄今最干净的一次单变量归因**。

**产业含义(与 §11.1 对话)**:

| 章节 | 主张 | 本日的补充 |
|---|---|---|
| **§11.1**(2026-10-16) | 「真机学习的数据门槛正在塌陷,路径不是更强的遥操作」 | ⚠️ **本日补上另一半:门槛塌了不等于数据越多越好。** 数据的**域对齐度**比**数量**更重要 |
| **本报告 §12.2** | —— | ✅ **数据策略应从「采集最大化」转向「域对齐最优化」**。对跨本体部署而言,**给错视角的数据是负收益** |

📌 **给数据工厂的直接建议(本报告推断,非论文主张)**:如果目标是**跨本体迁移**,投入应优先加在与目标本体**视觉域一致**的数据上;人类第一视角视频虽然便宜,却在跨本体场景下**可能为负**。这与「人类数据便宜所以优先用人类数据」的朴素直觉相反。

### 12.3 📌 本日三次「变量控制」的实测质量:本项目评估论文可信度的新维度

| 论文 | 对照设计 | 控制了什么 | 增益归因是否成立 | 本报告评价 |

🔑 **固化为本项目常设核查项**:

- 📌 **看到「我们快 X%」的主张,先查有没有算力对齐对照。** FastVLA 的 Table 4 是正面范例:它先自曝「实际预算超出名义目标 0.9–3.0%」,**主动为自己的增益设置了一个更严格的对照**。**作者愿意给自己设更难的对照,比对照本身更有信号价值。**
- 📌 **区分「工程贡献」与「架构必要性」。** LIN-SLAM 的 Table III 非常严谨,但它证明的是「我们的实现更快」,**不是「神经隐式比纯几何更值得跑」** —— ⚠️ 它**完全没与带回环优化的纯几何 SLAM(LIO-SAM / Kimera 类)对比**,而后者在重复走廊场景正是最直接的对手。**这个对照缺口使本文的核心架构主张无法被检验。**

### 12.4 ⚠️ LIN-SLAM 的两个「相对优势」在表内数字面前是打折的

**必须如实记录的核查结果**:

| 主张 | 表内证据 | 本报告判断 |
|---|---|---|
| 摘要:「achieves the **lowest overall mean ATE**」 | **128 线数据集上 LIN-SLAM 均值 0.141,而 CLID-SLAM 为 0.071**;且 LIN-SLAM 在 math easy(0.096 vs 0.071)与 quad easy(0.095 vs 0.067)均劣于对方 | ⚠️ **该表述在 128 线数据集上不成立。** 可能指「跨数据集整体」,但摘要措辞不精确 |
| 摘要/贡献:「endpoint closure errors **below 0.15 m**」 | 0.141 m(Corridor,1.47 km)/ 0.073 m(Basement,0.86 km),**无外部真值** | ⚠️ **论文自己写明「indicate endpoint consistency rather than trajectory-wide accuracy」。** 在 1.47 km 上回到起点的距离**不是轨迹误差上界** —— 途中可能已漂移 10 m 再漂回来。**该数字容易被误读,引用时必须带上这句限定** |

**✅ 相对站得住的成果**:运行时间 —— **49.211 ms/帧 vs PIN-SLAM 257.358 / CLID-SLAM 248.446,削减 80.9% / 80.2%**,以及 PIN/CLID 在 128 线上**共 4 条序列 Fail**。**「别人跑不完,它跑完了」这个结论比「它精度最高」更可信。**

## 13. 2026-10-20 增量观察:三篇同日研读交叉印证的三条产业链变化

本日三篇(均已取 arXiv HTML 全文)研读 **BlindBaoding**(爱丁堡大学,盲视二值触觉灵巧操控)/ **CoEvolve**(北大 + 人大 + BAAI,多机器人协作代码策略)/ **QuadrupedWBC**(东京大学 + 名古屋大学 + 里昂中央理工,四足机械臂全身控制),分属灵巧手 / 多机协作 / 足式操作三个不相关子领域。

### 13.1 🔴 触觉产业链出现了**第二条路线**,且它与 §12.5 的结论并不矛盾 —— 反而互补

**§12.5(2026-10-19)从 Spark-0 得到的结论**是:触觉的价值主要兑现于**预训练期**,部署期可以完全不装触觉传感器。**本日 BlindBaoding 给出了与之互补、但成本结构完全相反的另一条路线。**

| 维度 | **路线 A:训练期稠密触觉(Spark-0)** | **路线 B:部署期二值触觉(BlindBaoding)** |
|---|---|---|
| 触觉形态 | 稠密阵列(手套 / taxel) | **二值开关(12 FSR + 4 BioTac)** |
| 触觉的时机 | **仅训练期**,推理时移除 | **部署期全程在环** |
| 传感成本 | ⚠️ 论文未给(手套为可穿戴件,非机械手量产件) | ✅ **FSR 单价个位数美元级;12 个 FSR 总成本三位数美元** ⚠️ 单价为市场常识量级,非论文给出 |
| 采集成本 | 🔴 **1,000 h × 32 名操作者** | ✅ **零采集** —— 纯仿真训练 + 零样本迁移 |
| 训练算力 | 🔴 96 GPU × 400k 步 | 🟡 常规 PPO + Isaac Lab(论文未给 GPU 型号与时长 ⚠️) |
| 强项 | 跨本体泛化(**纯视觉部署 +19.27 点**) | **持续操控与异常恢复** —— 去掉触觉后整圈数 34.75 → 5.00(7× 差距) |
| 弱项 | 🔴 部署不装触觉 → **传感器渗透率低** | 🔴 **可靠性方差极大(34.75 ± 26.06,最小值 2 圈)**;传感器布局强耦合,标定常数需逐台重标 |
| 关键增量证据 | 2026-10-19 | **2026-10-20** |

🔑 **两条路线不是替代关系,而是「训练期用稠密、部署期用二值」的自然拼接:**

> BlindBaoding 的 STAT(Stuck-AT Taxels)**本质上就是「在训练期假装二值传感器会坏」的鲁棒性训练**。它与 Spark-0 的思路是同一族 —— **「训练时把世界做得更残缺」**。区别只在于残缺的对象(数据 vs 传感器)。

📌 **对触觉产业链的三条直接推论(本报告推断,非论文主张)**:

1. ✅ **「稀疏二值触觉」应当被正式列为一条独立技术路线,而不是「稠密触觉的降级版」。** 理由:二值化的唯一目的是**在仿真里廉价地复现真机的接触语义**;稀疏二值 + 故障随机化,恰好让**零真机采集**成为可能。这是稠密触觉做不到的。
2. ⚠️ **§12.5 的「部署期不装触觉」结论需要修订为「部署期可以只装二值触觉」。** 这**略微上调了触觉传感器的部署渗透率预期** —— 从「几乎不装」修正为「装很便宜的二值件」。
3. 🔴 **量产卡点从「采集成本」转移到了「标定一致性」**。Spark-0 的卡点是数据量(1,000 h),BlindBaoding 的卡点是**每台设备都要重标 +5/+2/−3 三个阈值常数**。**这对产线是致命的**:产线要的是可复制,不是每台都灵。⚠️ **建议把「标定是否可自动化」列为触觉赛道的独立追踪维度。**

### 13.2 🏭 多机器人协作的产业链第一次出现清晰的分层:**「编排层归基础模型,技能层归电机策略」**

CoEvolve 的贡献是产业性的,不是纯学术的:它给出了**「谁负责什么」的一个可运行的答案**。

| 层 | 由谁提供 | 本日证据 | 产业含义 |
|---|---|---|---|
| **编排层**(决定「怎么协作」) | **多模态基础模型**(GPT-5.4-mini / Gemini-3.5-Flash / Claude-Sonnet-4.6) | **三个 backbone 全部实现端到端成功(8/15)** | ✅ **基础模型厂商在这一层没有锁定风险** —— 换模型就能换编排策略,CoEvolve 本身证明了接口可移植 |
| **技能层**(决定「怎么走 / 怎么抓」) | **冻结的电机策略(SONIC)+ 任务技能封装** | 论文明确「**电机策略权重全程冻结**」 | ✅ **本体厂商保留全部价值** —— 电机策略的护城河不被稀释 |
| **验证层**(决定「这次算不算成」) | **物理执行验证器 + checkpoint 回滚** | EA 85.4%;**但 EA 94% 的 run 仍卡死** | 🔴 **这一层是当前最弱的**,且论文自己指出「checkpoint 接受只认证了被执行的那个转移,不认证剩余任务的可行性」 |

🔑 **对产业链最重要的推论(本报告推断)**:

> **基础模型厂商在这一层的议价能力被稀释了。** 因为编排层是**可替换的**(三 backbone 都能跑),而技能层是**不可替换的**(绑定具体本体)。**这与 VLA 领域的格局正好相反** —— 在 VLA 里,基础模型权重是护城河;在多机协作里,护城河是**电机策略 + 本体**。

📌 **宇树 G1 正在成为这一层的默认载体。** CoEvolve 用 **2 × G1**,QuadrupedWBC 用 **Go1**,此前收录的 LIN-SLAM 用 **Go2**。**本项目最近三篇论文中有两篇用宇树平台,而 G1/Go1 是可采购商品。** ⚠️ **这意味着宇树在「多机器人协作」这一新兴赛道上,同时占据了本体供给与科研默认平台两个位置 —— 而后者会转化为产业默认选项。建议把「宇树平台在已收录论文中的渗透率」列为常设跟踪指标。**

### 13.3 🔴 四足 + 臂的整机成本首次被量化为 **13.5 kg**,并与 Spot 路线形成对照

QuadrupedWBC 自研了 **1.5 kg / 6-DoF / 臂展 >60 cm** 的轻量臂(PLA-CF 打印件 + 内嵌碳纤维管),装在 Unitree Go1 上,整机 **13.5 kg**。
