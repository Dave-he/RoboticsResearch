## 6. 关键不确定性与风险

- **数据瓶颈**:高质量真实操控数据稀缺(sim2real gap)
- **可靠性**:长尾场景下的故障率未达工业可用
- **能源密度**:电池技术限制工作时间(典型 2-4 小时)
- **安全认证**:家庭场景下的 ISO/UL 标准尚未成熟
- **价格 vs 价值**:工业场景 ROI 仍未跑通(除特定重复任务)

### 9.1 强信号:力感知 VLA,两条路线均有硬数据

| | **Opt2VLA** (2609.23968) | **VisForce** (2609.25785) |
|---|---|---|
| 机构 | **Georgia Tech IRIM** | 未标注 |
| 路线 | **接口层**(力作为 VLA 显式输出) | **表示层**(力渲染进图像) |
| 底座 | **GR00T N1** | **π0.5** |
| 载体 | **Agility Digit** 人形(48 kg, 30 DoF / 20 驱动) | UR10 + **Inspire RH56F1** + 2× RealSense D405 |
| 数据 | **TO 合成 + 控制器 rollout** | **手部演示,每任务仅 25–30 次** |
| 关键结果 | C0 40.0% → C7 **82.2%** joint SR | π0.5 20% → VisForce **70%**(T2) |
| 项目页 | **opt2vla.github.io**(承诺发布力感知数据集) | 无 |

**⭐ 对行业最可操作的一条结论**:

> **力的「表征方式」比「有没有力」重要一个数量级。**

- Opt2VLA:力矩 **原生状态拼接 27.8% → 专用编码器 74.4%** → 加辅助未来力矩损失 **82.2%**
- VisForce:同样力接地图,**token 拼接 10/5/15% → cross-attention 70/55/40%**

**对厂商的直接影响**:

| 厂商 | 影响 |
|---|---|
| **NVIDIA(GR00T)** | 力接口范式可被 GR00T 直接产品化(本文底座即 GR00T N1) |
| **Physical Intelligence** | 同理(VisForce 底座即 π0.5)。**两家头部 VLA 已被独立验证** |
| **Inspire Robots** | RH56F1(6-DoF 低价手)+ VisForce ≈ **低成本力控平台**,算法增值层 |
| **Agility Robotics** | Digit 的差异化能力候选 |
| **物流/分拣集成商** | **变重量抓取**是真实痛点(视觉无法区分同外观不同重量的箱子,只有力能) |
| **力传感器厂商** | ⚠️ **中性,非利好** —— 两篇都**没省掉力传感器**,只换了编码方式。但可降规格(5 个粗量程驱动力) |

**另一条对 VLA 训练有价值的发现**:Opt2VLA 的 C8(全量微调 VLM)overall 75.6% < C7(冻结 VLM 骨干)82.2% —— **冻结骨干 + 只训 connector/action model 反而更好**。

### 9.2 最重要事件:7-DoF 全线性手做到 $500(冲击 §1.3)

**The Cartesian Hand(2609.25696)** · **Duke University** · **DARPA FoundSci + TIAMAT + ARO + ARL 资助**

**实测规格(全文,非推断)**:

| 指标 | 数值 | 对比参考 |
|---|---|---|
| **整机成本** | **~$500**(含七舵机) | Shadow Hand ~$100k;Allegro ~$20k+ |
| **3D 打印件** | PLA $30 / SLS Nylon 12 $50 | 仅占整机 **6–10%** |
| 质量 | **850 g** | ≈ Allegro 量级 |
| 自由度 | **7,全部线性** | Shadow 24 / Allegro 16(多旋转) |
| 峰值推力 | 170 N(理论) | 持续握持 **2 kg** |
| 关节速度 | ~60 mm/s | 偏慢,快速节拍可能不足 |
| 能力覆盖 | 35 物体 / 7 类机构化操作 | 实验室 + 制造 + 家居 |
| 开源 | 承诺 software + hardware,**未放出** | 需持续跟踪 |

**降本杠杆点(推断,基于 BOM 结构)**:打印件仅占 6–10% → **舵机占 BOM 约 85%**。**舵机选型与国产替代是该路线的真正杠杆点**,建议单独跟踪。

**对 §1.3 现有格局的判断**:

| 现有玩家 | 变化 |
|---|---|
| Shadow / Allegro / LEAP(高 DoF + 腱绳) | **性价比叙事被削弱** —— $500 做到 7 类机构化操作 |
| **平行夹爪**(Robotiq / DH-Robotics) | **最直接受益者**:加 $500 模块化扩展件即得"抓后可动"。这是**产品升级路径,不是竞品对抗** |
| **Inspire(RH56 系列)** | 同价位带另一条路线(该手走渲染力 + π0.5) |
| 实验室自动化(专用单工位设备) | **一只可换工具的手替代多个夹具** |
| 人形厂商(Figure / Tesla / 1X / Unitree) | 视觉与力控管线依赖多关节手标定,中期不构成替代,长期是成本压力 |

**DARPA 四个项目同时资助是强产业信号** —— 强于任何论文本身。

**最大风险**:**耐久数据完全缺失**(数千次循环磨损 / 舵机寿命 / 打印件疲劳),且无成功率统计。$500 是实验室价,**不是量产价**。

### 9.3 越界入册:野外空中操控(分量低于评分)

**Aerial Manipulation(2609.30521)** · **Penn State 航空航天系** · **IROS 2026 MoMA.v5 workshop,5 页**

全文核实后的实际情况:

- 任务:空中插销入孔(**20 mm 杆 → 50 mm 孔,离地 130 cm**)
- 策略:条件 Diffusion Policy,**80 次室内 UMI 手持演示**,**零样本**迁移到未见户外草地
- 状态估计:**FAST-LIO2**,无外部动捕
- 控制:全身 MPC,状态 $[p,v,\eta,\omega,q\in\mathbb{R}^4]$,输入 $[f,\tau,q_{ref}]$
- **样本量:室内 5 次 + 室外 3 次,共 8 次,全部成功**
- 结果:Norm. EE Error 室内 0.102 / 室外 0.104;Max Base Tilt 3.32° / 1.84°

**行业判断**:3/3 成功在 95% 置信下真实成功率下界仅约 **44%** —— 这**没有证明系统可靠**。该子方向瓶颈不在控制算法,而在**整机可靠性、失效安全、监管许可**。真实高空作业中**人工 + 安全绳至今优于任何无人系统**。

**协议处理**:§1 明确将无人机列为暂不纳入范围(单独建库),本篇标 `scope_note`,**不进入核心跟踪线**。

### 9.4 读 workshop 论文的默认折扣(新增方法论)

Aerial Manipulation 暴露了本项目的一个读法问题:摘要只说 "demonstrate successful outdoor manipulation tasks",**全文核实后是 3 次试验**。

- 本项目已把该约定记入协议执行经验

## 10. 2026-10-12 增量观察:成本结构正在被重估(三篇同期研读)

> 来源:[Dex-One2Many](reports/DexOne2Many_2610.12470_研读报告.md)(2610.12470)、
> [A Balanced Data Diet](reports/BalancedDataDiet_2610.12465_研读报告.md)(2610.12465)、
> [PhoneBot](reports/PhoneBot_2610.08737_研读报告.md)(2610.08737)

### 10.1 冲击 §1.1:开源双足人形的地板价被打到 $400 —— 但没有手

PhoneBot 把开源小型人形的入门价从 **$3,500**(HighTorque MiniPi)拉到 **约 $400**,且**感知套件反而最全**(手机相机 + IMU + 触摸屏 + 麦克风)。

**但必须同时记住三件事**:

| 事实 | 含义 |
|---|---|
| **无手臂** | 13 DoF 全部花在下肢(12)+ 躯干偏航(1)。**它是一台会走路的手机云台,不是能干活的人形** |
| **扭矩 1.4 N·m** | 舵机 DYNAMIXEL XL430-W250,2.0 rad/s 后力矩跌到 0.08 N·m。**成本优势完全是用扭矩换来的** |
| **同价位无工业能力** | 1.8 kg / 0.48 m / 平地-only / 无急停。**若目标是操控,$500–2,000 的桌面机械臂比它更有用且更便宜** |

> ⚠️ **本项目对该价格的读法**:"$400"是**教育与科研市场的真地板价**(此前 $3.5K),但**不是人形机器人的产业地板价**。**引用这个数字时必须同时说明它没有手。**

### 10.2 冲击 §3 成本结构:关节模组的成本底线被重新发现

PhoneBot 的 BOM 是本项目至今**唯一可核算到底**的:

```
13 × DYNAMIXEL XL430-W250 @ $23.90  =  $310.70   (占整机约 78%)
SBC + 结构件 + 电子件 + 电池(倒推)   ≈  $90
                                    ─────────
                                       约 $400
```

**这条算式揭示的成本结构事实**:在一台 13 DoF 的人形里,**关节占了 78%**。因此:

- **降价的第一杠杆永远是关节,不是结构件也不是算力**;
- ⚠️ **但 $23.90 的关节换来的是 1.4 N·m**。谐波减速器 + 无框电机方案单件 **$200–2,000 / 10–50 N·m**。**价格与扭矩是同一枚硬币的两面,不能只要便宜的**;
- **加手臂的算术**:13 舵机已占 78%,加 4–6 DoF 手臂 → 19–23 个舵机 → **即使沿用 $23.90 也要 $600–800,且 1.4 N·m 握力不足必须换舵机档位 → 成本优势被抹平**。⚠️ **这是 PhoneBot 路线的结构性天花板,不是工程排期问题。**

### 10.3 新增风险项:复用消费电子会引入新的锁定与安全债

| 新风险 | 证据 | 产业含义 |
|---|---|---|
| **GMS 锁定** | Honor 9 因无 Google 服务**直接无法使用 ARCore SLAM** | ⚠️ **「复用手机」的方案在部分品牌手机上功能降级**。评估此类平台时必须逐型号验证 |
| **低层环走 Wi-Fi** | 50 Hz(20 ms)+ UDP,**全文零延迟表征** | ⚠️ **控制稳定性依赖网络,这是与总线架构的根本差异**。家庭/儿童场景不可接受 |
| **无急停** | 训练代价含自碰撞/关节限位/脚滑惩罚,但**无运行时联锁、无物理急停** | 🔴 **任何面向家庭的消费级双足平台必须先补齐这一项** |
| **供应链单点** | 舵机依赖 DYNAMIXEL(ROBOTIS),而对比表里 OP3 也是 ROBOTIS | ⚠️ **国产同档舵机(Feetech / KST / MOONS)存在近似型号,替代性其实是有的,值得验证** |

### 10.4 反向信号:三篇共同削弱「真机数据工厂」叙事

本日三篇各自从不同角度削减数据/算力需求,但**共同指向同一结论 —— 瓶颈不在算法,在资产构造与真机保真度**:

| 论文 | 削减了什么 | 抬高了什么 |
|---|---|---|
| **A Balanced Data Diet** | 算力分配(不靠加环境,靠 Beta 核采样) | **~350 GPU·小时(H200/L40S)**;真机 37.5% vs 仿真 90.04% |
| **Dex-One2Many** | 数据(单条人类视频) | **≈3.15×10⁹ 环境步**;13 个物体中 **7 个仍需现成 CAD** |
| **PhoneBot** | 硬件成本($3.5K → $400) | **无手臂 / 无急停 / 无 ROS** |

> 📌 **对遥操作数据采集产业的净影响判断**:Dex-One2Many 表明 **3D 资产可以部分从单条视频生成**(SAM 3.1 + SAM 3D),但**"部分"是关键词 —— 7/13 仍需 CAD**。这**削弱但不推翻**遥操作工厂的必要性:**资产构造的前置成本可以被视频降低,但消除不了。**

### 10.5 意外收获:两样可以直接搬走的工程资产

本项目认为 PhoneBot 硬件新闻价值一般,但有两项**可复现性最高的技术细节值得单独归档**:

1. **矢状面镜像增强(sagittal mirroring)**:关节角对称误差 **0.254 → 0.003 rad**(约 85×),左右力矩不平衡 **0.205 → 0.034**。**可移植到任何双足/四足项目,零硬件依赖。**
2. **把消费级舵机的缺陷显式建模并在训练中随机化** —— 齿隙 **0.02–0.1 rad**(激活载荷 0.1 N·m)、摩擦 **0.069 N·m**、通电阻尼 **0.162 N·m·s/rad**、指令偏移 **±0.05 rad**、被动/主动刚度比 3.0。
   > 🔑 **这是全文最值得学的做法**:低成本硬件论文通常回避讲缺点,**PhoneBot 把齿隙、摩擦、力矩衰减全部量化并写进仿真**。⚠️ **注意 0.1 rad 齿隙在踝关节 ≈ ±5.7° 位置不确定性,直接对应跌倒风险** —— 这条应作为本项目评估任何低价关节模组时的必查项。

## 11. 2026-10-16 增量观察:三篇同日研读交叉印证的三条产业链变化

> 本节来自 [HiFun](reports/HiFun_2610.19518_研读报告.md) / [ACCRUE](reports/ACCRUE_2610.18596_研读报告.md) / [AdaptiveWBMPC](reports/AdaptiveWBMPC_2610.12972_研读报告.md) 三篇同日研读。**本节只记录对产业链有直接决策含义的发现,方法学细节见各篇报告。**

### 11.1 🔴 真机学习的数据门槛正在塌陷 —— 且塌陷路径不是「更强的遥操作」

本日两篇**互不相关的独立工作**给出了同向的硬数字:

| 来源 | 环节 | 传统做法 | 本日证据 | 量级差 |
|---|---|---|---|---|
| **HiFun**(HKUST+ETH) | 协调策略的初始数据 | **150–100 min/任务 人工臂手演示** | **13–34 min/任务 自动 DMP rollout**(成功率 100% / 100%,人工为 85% / 100%) | **约 1/4** |
| **ACCRUE**(NVIDIA) | 每阶段基座适配演示 | 每个新 SKU 一整套流程 | **仿真 1–50 条;真机 5–10 条**(SpaceMouse) | 量级下降 |
| **ACCRUE** | 新任务的后续 RL 交互 | 每任务从零重启,**全额支付** | **真机机器人时间节省 31.0–68.5%** | **1/3–2/3** |

🔑 **对产业链的直接含义**:

1. **「遥操作数据工厂」的成本模型需要修订。** 现行模型假设 *成本 ∝ 演示小时数*。HiFun 证明:**如果任务有可解析的运动学参考(一个位姿序列),演示量可以降到近乎为零**。**这不是「更便宜的遥操作」,而是「遥操作在很多工序上可以被自动生成替代」。**
2. **但必须同时记住 HiFun 保留的成本项**:运动学先验(**kinesthetic teaching < 5 min/任务**)+ 判别器数据(**4–13 min/任务**)+ 在环训练。**边际成本没有归零,只是从「小时级数据工程」转移到了「分钟级专家在场」。**
3. **受影响最大的产业环节**:机器人遥操作数据采集服务 / 数据工厂类创业公司。**若客户的工序具备可描述的几何结构,其护城河(采集规模)将被显著削弱。**

### 11.2 ⚠️ 「开源」正在从 2026 年机器人高影响力论文的默认变成承诺
