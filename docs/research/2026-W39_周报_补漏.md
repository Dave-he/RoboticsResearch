# 2026-W39 周报 · arXiv API 限流期补漏

## 事件复盘

`2026-09-20` 至 `2026-09-27` 共 8 天,`docs/daily/` 下的摘要均为 **0 篇命中论文**。
同一时期 `papers/daily/*.json` 的 papers 字段也为空,但 repos / models 字段正常,
说明 GitHub 与 HuggingFace 数据源未受影响,**问题集中在 arXiv `/api/query` 端点**。

`logs/daily_cron.log` 与 systemd service 日志显示,触发原因为 arXiv 的 Varnish
边缘缓存对 `/api/query` 返回 `HTTP 406 Not Acceptable`,即使把 `User-Agent` /
`Accept` 调成浏览器样式也无效。本次会话抓包确认:

- `curl https://arxiv.org/` → HTTP 200
- `curl https://arxiv.org/list/cs.RO/recent` → HTTP 200, 95KB HTML
- `curl https://export.arxiv.org/api/query?...` → HTTP 406(间歇性,MISS 命中 origin)

LNN 姐妹项目曾在 2026-09-03 记录过完全相同的故障模式,解决方案是 **/api/query
失败时回退到 arXiv 分类 RSS**(Varnish 对 RSS 端点更宽松)。本次同样把 LNN 的
`fetch_arxiv_rss` + `sync_with_origin` + `push_with_rebase` 移植到本项目。

## 已采取的修复

1. **Python 脚本**(`scripts/daily_robotics_research.py`)
   - 新增 `ARCHIVE_RSS_CATEGORIES` 常量(`cs.RO / cs.AI / cs.CV / cs.LG / cs.MA`)
   - 新增 `fetch_arxiv_rss()`,沿用既有 `keyword_score` + `is_robotics_relevant`
     过滤逻辑,按 RSS pubDate 反解为 ISO 日期
   - `request_json / request_text` 的 `Accept` 头改为更通用的 `*/*`
   - `main()` 在 `/api/query` 返回 0 论文或抛异常时,自动切换 RSS fallback
   - 新增"智能降级":若今日拉到的 papers / repos / models 比 JSON 里昨日的还少,
     沿用昨日数据,避免一次网络抖动把整周 digest 拖到 0 篇

2. **Bash 脚本**(`scripts/run_daily_robotics_task.sh`)
   - 新增 SSH key 自动探测(`id_github_dave-he` → `id_ed25519` → ...),
     解决 cron / 非交互 shell 找不到 key 导致 push 失败的隐性 bug
   - 新增 `sync_with_origin()`:fetch → 双向 ancestor 检查 → ff-only 合并或
     硬重置,消除"本地落后"导致的非快进 push
   - 新增 `push_with_rebase()`:push 被拒时自动 rebase → 重试,最多 5 次
   - 详细日志写入 `logs/daily_cron.log`(带时间戳)

3. **调度冲突**(`crontab`)
   - 禁用 `43 7 * * * ... # DAILY-ROBOTICS-RESEARCH`(原 cron 行)
   - 唯一调度源 = `~/.config/systemd/user/robotics-daily-research.timer`
     (07:00 CST + `Persistent=true` + `RandomizedDelaySec=10m`)
   - 这与 LNN 姐妹项目 2026-09-01 的修复方式一致:消除 cron / systemd
     双触发导致的同日重复 commit

## 本周可恢复的论文数据

arXiv RSS 端点 `https://export.arxiv.org/rss/{category}` 只返回 **过去 24-48 小时
的新公告**,无法追溯 2026-09-20 ~ 09-27 当日数据。换言之,**过去 8 天的 arxiv
论文数据无法事后补回**,只能从今天开始确保抓取稳定。

`docs/daily/2026-09-20 ~ 2026-09-27_robotics_research_digest.md` 仍保留为 0
篇命中状态,作为这次故障的留痕。`docs/daily/2026-09-28_robotics_research_digest.md`
已恢复正常,共 **80 篇**命中论文,跨 VLA / 具身 / 操控 / SLAM / 仿真 5 个子领域。
