## 核心问题

**这篇论文要解决的不是「怎么让机械臂抓得更准」,而是「怎么让移动操控策略在面对一个它从没见过的新场景时,自己决定底盘站哪、相机朝哪、手从哪个方向抓」。**

论文提出的核心概念是 **contextual whole-body manipulation(上下文全身操控)**,并给出一个很具体的诊断:

**1. 现有 sim-to-real 操控工作泛化的是「物体」,不是「物体–环境组合」。**
论文在 §2.2 结尾把话说明确:Dactyl / DeXtreme / Visual Dexterity / DexNDM 这一系列证明了**跨物体的动力学泛化**,但任务**只有手内重定向**;后续工作扩展了感知模态(点云、深度、RGB)与动作空间(双臂、人形),**但评估环境仍相对固定**。**没有一个是「同一套场景分布下训出、换个房间就废」的。**

**2. 论文认为根因是「让 RL 同时学两件事」。**
移动操控需要策略同时处理:①**场景推理**(底盘站哪、视角朝哪、怎么绕障)与 ②**接触丰富的交互**(怎么抓)。这两件事的**空间尺度、奖励形态、失败模式完全不同**。直接在全场景上做 RL,论文的说法是:策略「必须从高维场景观测中适配自身运动」,而**奖励必须在各种物体–环境配置下都保持有效** —— 两个要求同时压在一个网络/一个奖励上,两边都做不好。

**3. 论文提出的新视角:用「分解 + 蒸馏」而不是「更强的 RL」。**
关键洞察是 **global free-space reaching(全局空域接近)** 与 **local contact-rich interaction(局部接触交互)** 的**可分离性**:
- 前者**依赖场景上下文**(底盘位姿、可见性、避障),但**本质上是空域运动**,不需要接触物理;
- 后者**不依赖场景**,只需要物体的局部几何。

于是:用**向量化的环境感知 WBC** 处理前者(把策略从「学场景适应」里解放出来),用**少量局部 RL 专家**处理后者(每个专家只学一种抓握可供性,奖励极简),最后**把两者组合成的教师蒸馏成一个纯视觉的单策略** —— 学生**不再需要特权场景几何**,只用机载点云。

> **本报告的判断**:这篇论文真正的贡献**不是 91% 的抓取成功率**(那是结果),而是**「用可向量化的几何织物 WBC 替代在线优化 WBC,从而让「数千场景 × 数百物体」的联合训练规模变得可行」**这一**工程解锁**。没有前者,后面的规模叙事不成立;而 WBC 这一选择恰恰是最容易被引用者忽略的部分 —— 论文自己在 §2.3 末尾非常克制地说了:**「我们用 fabrics 不是因为它比优化型 WBC 更优,而是因为它提供固定的反应式计算图,可以在许多仿真环境中并行高效求值。」**

## 方法论与核心思路

### 3.1 整体框架:三段式(全局 WBC → 局部 RL → 单策略蒸馏)

```
[ 全场景 ] 目标物体 + 局部交互区 + 随机化场景几何/杂物/物理参数
     │
     ├── 教师 A:向量化 WBC（几何织物）
     │     · 输入:SE(3) 末端目标位姿 + 3D look-at 点
     │     · 输出:底盘速度 + 臂/手/颈部关节指令
     │     · 职责:空域接近、避障、保持注视
     │     ↓ 末端进入局部专家的初始化分布
     ├── 教师 B:局部 RL 专家（3 个抓握可供性）
     │     · top-down grasp / side-grasp / constrained side-grasp
     │     · 观测:物体包围盒、局部立方体与墙面构型、LEAP 关节、指尖位姿
     │     · 输出:相对末端指令 + 手关节指令
     │     ↓ 教师完整动作用于监督
     └── 学生:单一点云条件 Transformer（在线 DAgger）
           · 观测:深度相机 + LiDAR 点云(3072 点) + 本体感知 + 3D 目标物估计
           · 输出:32 维全身动作（底盘速度 + 臂/手/颈部增量关节目标）
```

### 3.2 关键创新一:向量化的环境感知 WBC(本文的真正解锁点)

**接口极简**:只吃一个 SE(3) 末端目标位姿 + 一个 3D look-at 点,**不需要显式底盘目标**。底盘怎么走由 WBC 内部决定。

**为什么必须用 fabrics 而非 QP/MPC**:论文 §2.3 给出了工程理由链:
- **QP 型微分 IK**(Pink、Mink):碰撞避让需要**带场景相关主动约束的约束求解**,**大批量并行执行困难**;
- **优化型 WBC**(PlaCo、OpenSoT)与 MPC(OCS2):约束与动力学更丰富,但引入**逐步/逐 horizon 的在线优化**,**批量求值昂贵**;
- **RMP / geometric fabrics**:用**度量加权的 pullback**组合行为,**计算图固定**,天然可批量化。

论文的核心论点是**「可并行求值」这个属性,而不是「最优性」**。这一点在 §2.3 末句被明说,本报告认为这是全文最容易被误读、也最重要的一句。

**组合方式(论文 Eq. 1)**:每个行为项由任务映射 $x_i=\phi_i(q)$、速度 $\dot{x}_i=J_i(q)\dot{q}$、度量 $M_i$、力项 $f_i$ 定义,所有项在关节空间 pullback 后组合:

$$
\left(\sum_i \mathbf{J}_i^\top \mathbf{M}_i \mathbf{J}_i\right)\ddot{\mathbf{q}} + \sum_i \mathbf{J}_i^\top\left(\mathbf{f}_i + \mathbf{M}_i\dot{\mathbf{J}}_i\dot{\mathbf{q}}\right) = \mathbf{0}
$$

**向量化**:对 $B$ 个环境,$\mathbf{q}\in\mathbb{R}^{B\times n}$,$\mathbf{J}_i\in\mathbb{R}^{B\times m_i\times n}$,$\mathbf{M}_i\in\mathbb{R}^{B\times m_i\times m_i}$ 全部是批量张量;pullback 退化为**批量矩阵乘**,项组合退化为**批量归约**。

**面向移动操控的新 fabric 项(论文自己的贡献,§3.1「Extending fabrics to mobile manipulators」)**:
- **base attractor (BA)** + **end-effector attractor (EEA)**,共用同一度量公式(Eq. 2),但**度量参数反向设置**:BA 取 $m_{\min}=0$(目标进入臂工作空间后**基座吸引子平滑消失**),EEA 取 $m_{\mathrm{far}}=0$(**只在近处才激活臂伸展**,避免过早伸臂)。论文明确:EEA 的 Jacobian **包含完整的 base-to-EE 链**,所以即使 BA 消失,**底盘仍在被驱动**。两者合成 **coarse-to-fine 全身接近**:远处底盘主导,近处臂优先(保证精度)。
- **注视**:加一个 $SO(3)$ 相机姿态吸引子,把光轴指向 look-at 点,另加一个弱的颈部姿态正则项。
- **碰撞避让**:用**碰撞球**近似机器人,批量计算到其他机器人球体与局部环境基元(**长方体、胶囊、球**)的距离;每个碰撞球诱导一个排斥 fabric。

**实测性能**:控制器 **60 Hz**,单卡支持 **4096** 个仿真环境,**每环境每控制步 0.03 ms**。

### 3.3 关键创新二:局部 RL 专家(把「奖励难设计」变成「奖励简单」)

论文采用 Dalal et al. 的局部策略形式(§3.2 引 [7]):**策略初始化在目标附近、观测在末端坐标系表达、动作是相对末端指令**。

论文明确列出这一形式的三条好处:
1. 在紧凑局部场景训练 → **降低仿真内存需求**;
2. 用**局部几何**而非全场景感知做条件 → **简化观测空间**;
3. 用 WBC 作为**结构化动作抽象** → **降低动作维度**。

最关键的是第 4 条(论文 §3.3 强调):**因为策略在末端坐标系表达,同一个局部行为可以在蒸馏时跨大量全场景上下文复用** —— 这才是「规模」成立的原因。

**三个专家对应三种抓握可供性**(§3.2 + Fig. 8):
- **top-down grasp**:区域有侧墙、顶部开放;
- **side-grasp**:从侧向接近,针对**细长物体**(如瓶子);
- **constrained side-grasp**:同样侧向抓,但**额外有顶墙**,要求物体**从侧面开口被抽出** —— 对应货架场景。

每个专家在**随机化立方体局部区域**内训练,随机化目标物体与墙面构型。论文说:「由于每个专家只需学一种抓握,**奖励规格化变得简单**,这有利于 RL 训练。」

**教师组合与交互切换(§3.3)**:每次 rollout 起点距目标 **0.2–2 m**。**approach 阶段**由 WBC 把末端带到局部交互区附近的 staging 位姿(避障 + 保持注视);**一旦末端进入局部专家的初始化分布,interaction 阶段开始**,专家输出相对末端与手指令,**仍由 WBC 执行**。WBC 的 look-at 目标设为物体位置。

### 3.4 关键创新三:局部 → 全场景的多教师蒸馏

**全场景生成**:对每个环境,采样一个目标物体与一个局部专家,然后生成包含**兼容该专家训练场景的局部交互区**的全场景布局。**专家类型决定有效场景族**:top-down → 桌面/抽屉/箱状场景;side-grasp → 细长物体场景;constrained side-grasp → 需要侧向抽出的货架状场景。周围场景几何、杂物与物理参数随机化。

**学生(§3.3 + 附录 E.4/E.5)**:
- **架构**:点云条件 Transformer(受 [51] 启发)。3072 点用 **PointNet set-abstraction** 编码(半径 0.1、64 邻居、128 输出 token),点 MLP `[3,64,64,64]`,投影 MLP 映到 124 维;每个低维状态用独立 MLP `[128,256]` → 124 维,共 **5 个状态 token**(Franka 关节 / ARX 关节 / LEAP 关节 / LEAP 控制目标差 / 目标物位置估计);拼 **4 维类型嵌入** → transformer 宽度 **$d_{\text{model}}=128$**。
- **Transformer**:编码器-解码器各 **6 层**,**8 头**,前馈宽度 **1024**;解码器用 $C$ 个可学习 action query + **1 个辅助 query**;action query 各自预测一个 **32 维**全身动作($\hat{A}\in\mathbb{R}^{B\times C\times 32}$)。**辅助 query 只允许 cross-attend 点云 token 与上一步目标估计 token,不允许 attend action query** —— 论文的意图是「迫使辅助头从几何而不是从动作输出估计物体位置」。
- **点云构造**:先采样场景与机器人网格点得到完整点云 $P_{gt}$,再**渲染**出传感器视角的点云 $P_{depth}=\text{RenderDepth}(P_{gt},T_{cam})$、$P_{lidar}=\text{RenderLidar}(P_{gt},T_{lidar})$。**这是「用渲染保真度换速度与显存」的交易**,论文自己明说。
- **局部裁剪**:从深度与 LiDAR 各取 (1) 以 Franka 基座为中心、半径 **1.5 m** 的**圆柱裁剪**(降采样到 1024 点)、(2) 以当前目标物估计为中心、半径 **0.5 m** 的**球形裁剪**(512 点)。合成 **3072 点**,变换到 **Franka 基座坐标系**。
- **观测全表(附录 E.4,Table 11)**:点云 3072×3、Franka 关节 7、ARX 关节 6、LEAP 关节 16、**LEAP 控制目标差 16**、目标物位置估计 3。
  > ⚠️ **「LEAP 控制目标差」值得单独抄下来**:$ \Delta q_{hand}=q^{target}_{hand}-q_{hand}$。论文的解释是:接触丰富的操控中,**指令的手部目标与实际达成的关节位置会不同**,这个残差**提供了有用的接触信息供反应性调整**。这是一个很朴素但很关键的设计。
- **目标物定位管线(§4 + 附录 E.6)**:真机上用 **SAM3** 给初始分割掩码 → 提升到 3D → 点云质心作初始估计;执行中策略以 **60 Hz** 自回归更新该估计,**SAM3 以 3 Hz** 在检测有效时覆盖修正。**若 SAM3 在 rollout 中失败,自回归跟踪继续;但 rollout 初始化之后的任何失败都计入报告的成功率。**
- **损失(附录 E.5)**:
$$
\mathcal{L}_{act}=\frac{1}{32BC}\sum_{b=1}^{B}\sum_{c=1}^{C}\|\hat{A}_{b,c}-A^{T}_{b,c}\|_2^2,\qquad \mathcal{L}_{obj}=\frac{1}{3B}\sum_{b=1}^{B}\|\hat{y}_{obj,b}-y_{obj,b}\|_2^2,\qquad \mathcal{L}=\mathcal{L}_{act}+0.1\mathcal{L}_{obj}
$$
  辅助头预测**有界增量** $\hat\delta_{obj}\in[-1,1]^3$,$\hat o_{t+1}=o_t^{anchor}+s_{obj}\hat\delta_{obj}$,$s_{obj}=0.01$ m;训练时**扰动目标物估计**以防策略过度依赖完美锚点。
- **多教师 DAgger**:每个 GPU rank 跑一个专家专属的全场景环境与教师,**共享同一份学生权重**,梯度跨 rank 平均;**每 rank 512 个环境**。**训练前 10k 梯度步全部执行教师动作,之后 10k 步线性衰减到 0**;若成功条件**连续 100 个仿真步成立则提前 reset**。

### 3.5 与已有方法的本质区别

论文 §2.2 末尾对 ManipGen(同样是局部策略 + 蒸馏)给出了明确的区分,值得原样记住:

> ManipGen 依赖**一个独立的推理期运动规划器**。这个假设对移动操控在非结构化场景中很困难,因为**稳健的全身规划必须直接从部分机载观测出发**。我们改为把局部策略与全身运动生成**蒸馏成单个端到端策略**,移动操控**推理期不需要全身运动规划器**。

具体对照(论文 §5 进一步解释):ManipGen 用点云条件局部策略 + **AIT\* 运动规划** + **VLM 指定规划目标**;这在**中间目标选择**上形成瓶颈 —— **VLM 指定的规划目标不考虑后续操控,常常让手臂停在奇异位形附近**。COWBOY 把接近与操控**一起蒸馏**,消除了这个中间决策。

论文还点出一个重要的**训练成本对比**:
> ManipGen 训练**数千个单物体专家**,而 COWBOY 的**每个专家跨数百个物体训练**。权衡是:**只有少数几个专家能监督数千个全场景–物体上下文。**

## 核心公式提取

### 公式 1:fabrics 的关节空间组合(几何织物)

$$
\left(\sum_i \mathbf{J}_i^\top \mathbf{M}_i \mathbf{J}_i\right)\ddot{\mathbf{q}} + \sum_i \mathbf{J}_i^\top\left(\mathbf{f}_i + \mathbf{M}_i\dot{\mathbf{J}}_i\dot{\mathbf{q}}\right) = \mathbf{0}
$$

**符号解释**:
- $\mathbf{q}\in\mathbb{R}^n$ —— 关节位置向量;$\ddot{\mathbf{q}}$ —— 由织物求出的加速度
- $\mathbf{J}_i$ —— 第 $i$ 个任务映射的 Jacobian;$\mathbf{M}_i$ —— 度量(状态相关的优先级);$\mathbf{f}_i$ —— 力项(期望行为)
- 求解后施加 **fabric energization**,再积分成底盘速度与关节位置指令

**为什么重要**:它是**「可批量求值」这一属性的数学来源**。所有项的 pullback $\mathbf{J}_i^\top\mathbf{M}_i\mathbf{J}_i$ 都是批量矩阵乘,组合是批量归约 —— **这正是 4096 环境 / 0.03 ms 的技术根因**。对比 QP 型 IK 需要带主动约束的约束求解、MPC 需要逐 horizon 在线优化,这两者在批量仿真里都不可行。

### 公式 2:BA/EEA 的距离自适应度量

$$
\mathbf{M}(\mathbf{x})=\eta\,\mathrm{diag}\!\left(m_{\mathrm{far}}+\left(m_{\min}-m_{\mathrm{far}}\right)\left[\frac{1}{2}\tanh\!\left(-\alpha_{m}\left(\mathrm{dist}(\mathbf{x},\mathbf{x}^{\star})-r_{m}\right)\right)+\frac{1}{2}\right]\right)
$$

**符号解释**:
- $\mathbf{x}$ —— 当前状态(BA 用平面基座位姿;EEA 用末端位姿);$\mathbf{x}^{\star}$ —— 目标
- $r_m$ —— **过渡半径**;$m_{far},m_{min}$ —— 远离/接近目标时的度量
- $\eta,\alpha_m$ —— 缩放与平滑系数

**为什么重要(这是本文最优雅的一处工程)**:BA 取 $m_{\min}=0$、EEA 取 $m_{far}=0$ —— **同一族公式,靠两个端点参数取 0 实现「粗到细」的职责交接**,而不是靠手写 if-else 或切换逻辑。论文明确指出:EEA 的 Jacobian 含完整 base-to-EE 链,所以 **BA 消失后底盘仍被驱动**,这保证了交接是无缝的。

### 公式 3:教师动作 → 学生归一化动作空间的编码

$$
a^{b,T}=\frac{R_{\mathrm{SE(2)}}(-\psi_t)(q^{b,*,T}_{t+1}-q^{b}_t)}{\Delta t},\qquad a^{r,T}=\frac{q^{r,*,T}_{t+1}-q^{r}_t}{\alpha_r \Delta t(q^{max}_r-q^{min}_r)},\quad r\in\{f,h,v\}
$$

**符号解释**:
- $q^b_t=(x_t,y_t,\psi_t)$ —— 基座平面位姿;$R_{\mathrm{SE(2)}}(-\psi_t)$ —— 把世界系底盘增量转到本体系
- $q^{r,*}_{t+1}$ —— WBC/专家给出的部件 $r$ 的关节目标;$\alpha_f=0.6$(Franka)、$\alpha_h=3.0$(手)、$\alpha_v=0.6$(视觉臂)
- $\Delta t=0.01667$ s(60 Hz)

**为什么重要**:教师是**任务空间**(相对末端指令 + 关节目标),学生是**归一化本体空间**。这条式子是**两种动作语义之间的唯一桥梁** —— 它决定了「教师能教会学生什么」。⚠️ 注意 $\alpha_h=3.0$ 明显大于另外两个 0.6,这是**手部动作尺度的放大系数**,论文未解释其取值依据,本报告视为复现时需要自行标定的超参。

### 公式 4:蒸馏损失

$$
\mathcal{L}_{act}=\frac{1}{32BC}\sum_{b=1}^{B}\sum_{c=1}^{C}\|\hat{A}_{b,c}-A^{T}_{b,c}\|_2^{2},\qquad \mathcal{L}=\mathcal{L}_{act}+0.1\mathcal{L}_{obj}
$$

**符号解释**:$A^T\in\mathbb{R}^{B\times C\times 32}$ —— 由公式 3 转换后的教师动作块;$y_{obj}$ —— 目标物位置真值标签

**为什么重要**:损失是**纯行为克隆式的 MSE**,**没有任何 RL 项**。这是本文的另一个方法论选择:**教师(RL 训练)负责「什么是好行为」,学生(DAgger)负责「从部分观测复现好行为」**。所有 RL 的信用分配难题都留在教师侧解决。

### 公式 5:物体传送鲁棒性增强的循环课程(附录 E.7)

$$
p_{raw}(i)=\begin{cases}0,& i<n_0\\[2pt] \frac{0.5}{n_1-n_0},& n_0\le i<n_1\\[2pt] a(i+1-n_1)^2+\frac{0.5}{n_1-n_0},& n_1\le i<n_2\end{cases},\qquad p_{tele}(t)=c(t)\,p_{raw}(t\bmod n_2)
$$

**符号解释**:
- $i=t\bmod n_2$ —— 循环内位置;$c(t)=\min(t/N_{curri},1)$ —— 全局课程系数
- 超参:$\rho_{tele}=0.2$、$N_{curri}=200{,}000$、$n_0=10$、$n_1=150$、$n_2=300$;$a$ 取值使二次分支在周期末达到概率 1.0

**为什么重要**:「**传送目标物体但不重置机器人**」是一个针对性很强的增强 —— 强迫学生从**非分布内的感知与控制状态**恢复,同时教师仍提供正确监督。**只作用于 20% 的缓存环境**,且只重置物体状态。⚠️ 这也意味着 **80% 的训练环境没有这项增强**。

## 局限性与未来展望

### 一、论文自述的局限(§6,仅一段)

论文的 Limitations 只有一小段,且**只有一条**:
> 对我们的全身抓取策略,**抓取策略是从场景与物体上下文推断出来的,但许多物体根据下游用途允许多种有效抓取**。因此**功能性的全身抓取需要超出场景本身的条件**。

**这条自陈很关键但也很克制**:它承认了**当前方法学到的是「几何上可行的抓法」,而不是「用途正确的抓法」**。换句话说 —— 90% 的成功率里,有一部分是「抓起来了,但抓错了地方」。论文没有量化这一部分有多大。

### 二、本报告在阅读中发现的额外问题

**1. 「上下文适应」这个核心主张缺少定量证据。**
全文的卖点是 context-aware behavior(自动适配底盘位姿、视角、抓取策略),但**没有任何一个指标测量「适配的正确性」**。91% 是在**给定场景里成功**;「在给定的场景里选了**场景所允许的**抓取方式」是另一回事。论文给出的都是**个例展示**(Fig. 1 的瓶子 vs 毛绒玩具)。**这是全文最大的证据缺口** —— 主张与度量之间有缺口。

**2. 91% 这个数字的统计口径需要打折。**
- 论文给的是**跨 24 场景 × 25 物体 × 3 朝向的平均值**,**没有给置信区间**,也没有给**逐场景的完整数字表** —— 只有一张 Fig. 5 的可视化。
- 平均值**掩盖了场景间差异**:论文自己说货架场景明显更差。**「24 个场景平均 91%」与「最差场景 60%」是完全不同的产业含义。**
- **失败判据是二元的**(抬 10 cm + 无碰撞),**不区分抓取质量**。抓在物体边缘但抬起来了算成功。
- ⚠️ **每场景「另抽 5 个」的那部分**,论文在 Fig. 6 说明两个物体集都未见训练,但**没有把「固定 20 物体」与「随机 5 物体」的成功率分开报告** —— 而这两个数字的含义完全不同(前者测上下文适应,后者测物体泛化)。**合并报告等于把两个不同的实验混成一个。**

**3. 「零样本」的措辞需要限定。**
论文说「COWBOY **achieves zero-shot sim-to-real transfer**」。准确地说:**sim-to-real 是零样本**(真机不需要任何真机数据微调);但**物体与场景的泛化并不是零样本** —— 真机评测的 100 个物体与 24 个场景在仿真训练中**都没有出现过**,这一点论文自己也强调(「Both sets of objects not seen in training」)。所以「zero-shot」指的是**不采真机数据**,不是「不需要任何泛化」。

**4. 开放性:连续第三个批次未兑现,且这次的缺口更彻底。**
本项目在 W43 周报中记录过「开源连续三个批次未兑现后,10-22 批次出现反转(BiDex-100 达 MIT + 212 YAML + HF/ModelScope)」。**本次批次(2026-10-23 ~ 10-26)的四篇 read_now 中,本篇 COWBOY、SP-HLM、AtomicRL 三篇全部无代码可用**:
| 论文 | 代码 | 证据 |
|---|---|---|
| COWBOY | ❌ 无 | 项目页实测无 GitHub 链接;GitHub 搜索零结果 |
| SP-HLM | ❌ 仅项目页 | `github.com/windydauy/SP-HLM` **已克隆核实**:只有 `index.html` / `site.js` / `styles.css` / `assets-images.zip` / 一个 GH Pages deploy workflow,**无任何模型/训练/推理代码**;**0 star、0 fork、无 LICENSE** |
| AtomicRL | ❌ 无 | 全文无代码发布声明;依赖开源框架 RLinf,但本方法未进该仓库 |

这**直接反转**了 10-22 的乐观判断。⚠️ 更值得注意的是:这三篇的**基座模型全是开源的**(π0.5、OpenVLA-OFT、GR00T N1.7、SAM3、Kimodo、SONIC、RLinf)—— **方法层全部闭源,底座层全部开源**。这个模式对产业选型有直接含义:**「开源基座 + 闭源方法」正在成为 2026 年 Q4 机器人论文的默认形态。**

**5. 对 ManipGen 的对比在训练预算上不完全公平。**
论文自己在 §5 末坦承:ManipGen **训练数千个单物体专家**,COWBOY **只有 3 个专家跨数百物体**。但表 1 的对比**没有对齐训练预算** —— 没有报告双方的环境数、GPU 时长或交互次数。因此「92.4 vs 63.1」**不能读作「COWBOY 的方法更好」**,只能读作「**在这两个具体系统的不对称预算下,COWBOY 更高**」。论文的措辞其实是克制的(「ManipGen uses ... This design creates a bottleneck for intermediate-goal selection」),但表 1 的排版容易让读者读成方法层面的胜负。

**6. 训练成本门槛很高。**
**8× A6000、约 60 小时**只是**学生蒸馏**阶段。论文**没有披露**:
- **三个局部 RL 专家各自的训练开销**(多少环境、多少步、多少 GPU 时)—— 这部分被藏在「Details are provided in Appendix D」里,而本报告**未在附录中找到专家训练步数与 GPU 数的明确数字**;
- 全场景生成与传感器模拟的工程成本;
- 复现所需的 TidyBot++ 硬件 + Franka + LEAP Hand + ARX X5 + RealSense D435 + Unitree L2 的**完整硬件清单成本**。

**7. 感知管线依赖 SAM3 的周期性修正,鲁棒性边界未测。**
真机上 **SAM3 3 Hz + 策略 60 Hz 自回归**。论文说「若 SAM3 在 rollout 中失败,自回归跟踪继续」,但**没有报告 SAM3 的实际失败率**,也没有做「禁用 SAM3 修正」的真机消融。考虑到表 3 显示**去掉主动视觉真机就掉到 46.7%**,**感知链路的单点依赖是实实在在的部署风险**。

**8. 「碰撞球 + 长方体/胶囊/球」的环境几何简化是 sim2real 的一处已知软肋。**
论文的碰撞避让只处理**基元**环境。真实场景的**柔性物体(衣物、绳、薄膜)、可变形家具、液态/散落物**无法用这些基元表达 —— **而这些恰恰是「野外场景」最容易出现的东西**。论文的 24 个野外场景都恰好是**刚性、可基元化**的。

### 三、未来方向

**论文提出的**:
1. **功能性全身抓取**:需要「超出场景本身的条件」(例如目标物体的**用途/任务语义**),这在 §6 被明确列为方向。
2. 「铰接物体交互等额外部署技能可通过训练更多局部专家加入」 —— 见 §3.2 末句。

**本报告推断的(论文未提但由其数据直接支持)**:
- **「上下文适应」应当被做成可度量的指标。** 论文已经具备全部素材:三个专家(top-down / side / constrained side)本身就是**可判定的抓取方式标签**。**统计「策略选择的专家与场景几何所允许的专家是否一致」**,会得到一个远比 91% 更有信息量的数字 —— 它能直接回答「策略是真的在推理上下文,还是只是学会了「在深度图上抓」这种通用行为」。**论文的 Fig. 5 逐场景图看起来已经在做这件事,但没有汇总成指标。**
- **Table 3 的「No sim. render → 真机 0%」应当被单独提炼为一个可迁移的教训。** 这不只适用于本文:**任何用更完整/更完美的仿真观测训练、在真机上依赖部分观测的系统,都面临同一风险**。这与本项目在 §10 月度合成中记录的「**指标分离**」是同一类方法论:「模拟分数高」和「真机分数高」必须分列。
- **教师的 98.4% 到达率是整条链的上限。** 分解法的天花板由 WBC 决定。**报告这个上限**(而非只报最终成功率)应该成为这类「分解 + 蒸馏」论文的标准披露项。

**先给结论:这个框架当前最适合的角色是「移动操控整机的参考架构」与「货架/抽屉场景的可行性证明」,而不是「能力验收标准」。** 91% 的抓取成功率离产线验收标准(通常要求 ≥ 99% 单次成功率、且往往带人工干预兜底)仍有明显距离,但**它的方法论结构 —— 分解 / 蒸馏 / 主动视觉 —— 对产业界有直接可借鉴价值**。
