## 🧠 关键概念笔记(Zettelkasten)

### 力感知 VLA(Force-Aware VLA)

> 建卡日期:2026-09-29 · 来源:Opt2VLA(2609.23968)+ VisForce(2609.25785)同日入册
> **2026-09-29 补全**:两篇均已取 PDF 全文,证据强度远超摘要所示

**核心命题**:当前 humanoid VLA 把动作输出限制在**几何运动目标**,导致"用多大力"这个决策在 VLA→控制接口处**结构性丢失**。两条论据:

1. **几何相同、力不同** —— 举空杯 / 装满水 / 递给别人,末端轨迹可完全一致,差别只在力。几何接口下这三种情况是**同一个动作**
2. **接触后视觉失效** —— 接触瞬间起,观测被遮挡/运动模糊/形变污染,而这恰恰是最需要精细力调节的窗口

**关键区分 ——「力作为观测」vs「力作为参考」**:

| 角色 | 做法 | 性质 |
|---|---|---|
| 观测/反馈 | 力输入策略,策略自行反应 | **被动** |
| **显式参考** | 策略**输出**期望力,与几何目标并列 | **主动** ← Opt2VLA 的主张 |

**两条实现路线(均已有定量支撑)**:

| 路线 | 代表 | 底座 | 载体 | 关键结果 |
|---|---|---|---|---|
| **接口层** | Opt2VLA | GR00T N1 | Agility **Digit** 人形(48kg/30DoF) | C0 40.0% → C7 **82.2%** joint SR |
| **表示层** | VisForce | **π0.5** | UR10 + Inspire RH56F1 | π0.5 20% → VisForce **70%**(T2) |

**⭐ 本项目最重要的方法论结论(跨两篇的共同发现)**:

> **力的「表征方式」比「有没有力」重要一个数量级。**

- **Opt2VLA**:同样的力矩信息,**原生状态拼接 27.8% → 专用编码器 74.4%**(2.7 倍)→ 再加辅助未来力矩损失 **82.2%**
- **VisForce**:同样力接地的图像,**token 直接拼接 10/5/15% → goal-conditioned cross-attention 70/55/40%**(3.7–11 倍)

这条结论的普适性**远超两篇各自的任务本身**,建议作为本项目的核心方法论沉淀。

**数据路线完全相反且都成立**:

| 路线 | 做法 | 代表 |
|---|---|---|
| **合成** | 全身 TO 在规定接触 wrench 下联合解出运动与关节力矩 → 物理一致的力矩监督 | Opt2VLA |
| **极少真机数据** | 手部演示采集,**每任务仅 25–30 次** | VisForce |
| **零样本迁移** | UMI 手持采集 80 次室内演示 → 未见户外不重训 | Aerial Manipulation(越界入册) |

**失效模式相反**:

- **Opt2VLA 策略强、执行弱** —— joint SR 82.2%,但真机力跟踪 MAE 擦拭 **7.0 N** / 推箱 3.9 N / 抓取 1.7 N(R²=0.98/0.70/0.80)。瓶颈在**低层 RL 控制器**,不在高层策略
- **VisForce 轻量但绝对值低** —— 40–70% 成功率,且换手需重做标定管线

**另一条对 VLA 训练实践有价值的发现**:Opt2VLA 的 C8(**全量微调 VLM**)overall 75.6%,**低于** C7(冻结 VLM 骨干)的 82.2% —— 冻结骨干 + 只训 connector/action model 反而更好。

**未解问题**(持续跟踪):
- `task-specific WBC` 是否会抵消 VLA 通用性?(Opt2VLA 自承每任务一套控制器)
- 接触状态(是否贴合/滑移)仍无显式表达,只有力
- 两篇都**无法省掉力传感器**,只是换了编码方式 → 对传感器厂商是中性而非利好
- VisForce 标定管线与具体手部 URDF 强绑定,跨手泛化未验证
- Opt2VLA 的力判定允许 5 N 容差,而擦拭真实 MAE 就是 7.0 N → 82.2% 须结合容差一起看

### 构型创新 vs 自由度堆砌(末端执行器)

> 建卡日期:2026-09-29 · 来源:The Cartesian Hand(2609.25696)
> **2026-09-29 补全**:全文实测数据已获取

**核心议题**:灵巧手的"灵巧"是否必须来自**高自由度**?

Cartesian Hand 用 **7 个全平移 DoF** 实现机构类物体(螺纹/枢轴/导轨/柱塞/扳机)在位操控,方法是**在末端执行器内把"抓"与"相对运动"正交解耦**:

| 关节 | 语义 | 轴向 |
|---|---|---|
| $q_0$ / $q_4$ | 基座 / 辅助夹爪开合 | y |
| $q_1,q_2$ / $q_5,q_6$ | 各自的指尖平移(成对协调) | x |
| **$q_3$** | **双夹爪相对间距**(初版遗漏的第三维度) | z |

**由此派生的控制优势**:全平移关节使指尖运动学**构型无关**,指尖位姿是行程的线性叠加,逆运动学退化为**线性方程组**,无多解、碰撞检测可在笛卡尔空间做。

**⭐ 硬数据(全文实测,非推断)**:

| 指标 | 数值 |
|---|---|
| 整机质量 | **850 g** |
| 外形(完全闭合) | 166 × 100 × 76 mm |
| 指尖 / 夹爪 / 间距行程 | 65 / 52 / 52 mm |
| 关节速度 | ~60 mm/s |
| 舵机峰值堵转力矩 | 1.39 N·m → 理论推力 **170 N** |
| 抓持能力 | **持续握持 2 kg 瓶体** |
| **3D 打印件成本** | **PLA $30 / SLS Nylon 12 $50** |
| **整机成本** | **约 $500(含七舵机)** |
| 机构 / 资助 | **Duke University** / **DARPA FoundSci + TIAMAT + ARO + ARL** |

**控制特性(初版未发现)**:**无视觉反馈** —— 纯接触自感知。夹爪闭合到接触为止,**终态夹爪位置直接反推物体尺寸**(盖子直径、物宽度),据此决定指尖位移与重抓次数。AprilTag 已嵌入但视觉反馈留作 future work。

**降本杠杆点(推断,但基于实测 BOM 结构)**:打印件仅占整机 6–10% → **舵机占 BOM 约 85%**。降本关键在**舵机选型与国产替代**,不在结构设计。

**行业含义**:若成立,"高 DoF + 腱绳传动"路线的**性价比叙事被削弱**;平行夹爪厂商可加 $500 模块化扩展件即得"抓后可动"能力 —— 这是**产品升级路径而非竞品对抗**。**DARPA 四项目同时资助是强产业信号,强于任何论文本身。**

**待验证(下轮必查)**:耐久数据(数千次循环磨损/舵机寿命/打印件疲劳 —— **工业场景必问项,论文完全缺失**)、35 物体的成功率统计、开源是否落地(项目页 generalroboticslab.com/cartesian_handv1)。
